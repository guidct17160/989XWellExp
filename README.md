# WellX989 Workspace

This repository is structured into 3 main project directories:

```
WellX989-expo/
├── app/          # Mobile Application (Expo / React Native)
├── backend/      # Backend API Server (Node.js Express)
└── frontend/     # Web Admin & HR Dashboard (React / Vite)
```

## Folder Breakdown

### 📱 Mobile App (`/app`)
The React Native / Expo app for iOS and Android.
- **Entry Point**: `app/App.js`
- **Source Code**: `app/src/`
- **Run Command**:
  ```bash
  cd app
  npm install
  npm start
  ```

### ⚙️ Backend Service (`/backend`)
Express.js REST API server handling authentication, attendance, leaves, and missions.
- **Entry Point**: `backend/src/server.js`
- **Run Command**:
  ```bash
  cd backend
  npm install
  npm run dev
  ```

### 💻 Frontend Web (`/frontend`)
React Web Application for HR Administrators and Management Dashboard.
- **Entry Point**: `frontend/src/App.jsx`
- **Run Command**:
  ```bash
  cd frontend
  npm install
  npm run dev
  ```
