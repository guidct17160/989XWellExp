# เทสเคสหน้า Login / ลืมรหัสผ่าน / ตั้งรหัสผ่าน / รีเซ็ตรหัสผ่านพนักงาน (เว็บแอดมิน)

เทสอัตโนมัติด้วย Playwright เฉพาะเคสระดับ **Critical** และ **High** ส่วนระดับ Medium / Low ให้ทดสอบมือเมื่อมีการแก้หน้านี้
โค้ดเทสอยู่ที่ `frontend/e2e/` (ทุกเคส mock API ไม่ต้องเปิด backend)

| ระดับ | ความหมาย | จำนวน | วิธีทดสอบ |
|---|---|---|---|
| Critical | พังแล้วเข้าระบบไม่ได้ หรือเป็นช่องโหว่ความปลอดภัย | 11 | ออโต้ |
| High | ฟังก์ชันหลักที่ผู้ใช้ต้องใช้ / ป้องกันความผิดพลาดสำคัญ | 22 | ออโต้ |
| Medium | ควรถูกต้อง แต่มีทางเลี่ยงหรือกระทบน้อย | 21 | ทดสอบมือ |
| Low | ความสะดวก / รายละเอียดเล็กน้อย | 12 | ทดสอบมือ |

## วิธีรัน
```
npm run test:e2e            # รันเทสออโต้ทั้งหมด (Critical + High)
npm run test:e2e:critical   # รันเฉพาะ Critical
```
